# 插件能力说明

`sr-plugin-anime` 为 Structured Renamer 提供动画作品查询和视频尺寸读取能力。
本文对应插件 `0.1.0`，支持宿主 `>=0.2.0,<0.3.0`。
插件须与宿主安装在同一 Python 环境中，通过 `sr.plugins` 入口注册为 `anime`。

## 能力一览

| 能力名称 | 用途 | 所需资源 |
| --- | --- | --- |
| `anime:bangumi_search` | 根据标题查询作品中文名、放送日期 | 宿主 HTTP 资源、可访问 Bangumi API 的网络 |
| `anime:file_resolution` | 读取本地视频的实际宽高和尺寸文本 | 宿主媒体探测资源，通常需要 PATH 中的 `ffprobe` |

## 查询动画作品：`anime:bangumi_search`

向 Bangumi 的 `POST /v0/search/subjects` 接口发送标题，限定搜索动画类型。

### 输入和输出

| 方向 | 端口 | 类型 | 含义 |
| --- | --- | --- | --- |
| 输入 | `title` | 文本 | 非空作品标题 |
| 输出 | `name_cn` | 文本 | Bangumi 条目的中文名 |
| 输出 | `date` | 文本 | 有效的 `YYYY-MM-DD` 日期，如 `2020-10-03` |

搜索结果中，优先选择原名 `name` 或中文名 `name_cn` 与输入标题一致的条目；比较时忽略大小写和空白字符。
没有精确匹配时，使用服务端返回的第一个可用条目。因此，模糊标题或同名作品可能需要人工核对。

选中条目后，中文名和日期都必须有效，即使规则只映射其中一个输出。
输入为空、没有可用条目、字段缺失、字段类型错误或日期非法时会报错，不会自动回退到原名或其他条目。
网络请求失败也会向宿主报告错误。

### 规则示例

以下片段放在规则的 `extensions` 中，前面的 `parse` 需要先提取 `title`：

```yaml
extensions:
  - name: anime:bangumi_search
    inputs:
      title: title
    outputs:
      name_cn: title_cn
      date: year:date_format("%Y-%m-%d", "%Y")
```

映射左侧是插件端口，右侧是规则字段。这里生成 `title_cn` 和 `year`，供后续渲染使用。
插件输出完整日期，示例中的年份提取由宿主 `date_format` 操作完成。
该能力没有自定义配置选项。

## 读取视频尺寸：`anime:file_resolution`

从宿主获取当前文件路径及后缀，探测文件中的媒体流，选择第一个宽高均为正整数的视频流。
尺寸来自视频流元数据，不从文件名中的 `1080p` 等标签推断。

### 输入和输出

无需映射输入端口，当前文件路径及后缀由宿主自动提供。

| 输出端口 | 类型 | 含义 | 示例 |
| --- | --- | --- | --- |
| `width` | 文本 | 视频宽度，单位为像素 | `1920` |
| `height` | 文本 | 视频高度，单位为像素 | `1080` |
| `resolution` | 文本 | `宽x高`，使用小写字母 `x` | `1920x1080` |

支持后缀：`.mkv`、`.mp4`、`.m4v`、`.avi`、`.mov`、`.webm`、`.ts`、`.m2ts`、`.mts`、`.mpeg`、`.mpg`、`.vob`、`.wmv`、`.flv`、`.ogv`、`.3gp`、`.3g2`。

其他后缀不适用此能力，包括 `.ass` 字幕和 `.mka` 音频。
支持后缀的文件若不存在有效视频流，或媒体探测失败，会报错。
多视频流文件按探测结果顺序选取，不自动选择最高分辨率。

### 规则示例

```yaml
extensions:
  - name: anime:file_resolution
    outputs:
      width: width
      height: height
      resolution: resolution
```

可以只映射需要的输出，例如仅保留 `height: height`，在渲染模板中使用 `{height}p`。
`height` 是实际像素高度，不会自动归类为标准的 `720p`、`1080p` 等档位。
该能力没有自定义配置选项。

## 与重命名规则配合

完整使用示例见 [demo/rule.yaml](../demo/rule.yaml)：先解析文件名，再查询作品、读取视频高度，最后将中文名、年份、集号等字段组合成新文件名。

文件名解析、分组关联、发布组和字幕语言映射、日期格式转换，以及预览、重命名和撤销由宿主及规则提供。
字幕和音频可以通过宿主分组机制使用关联视频的高度；插件本身不会探测字幕尺寸，也不会自动寻找配套视频。
demo 中固定的 `s01` 来自规则模板，插件不识别季号、集号，也不查询字幕语言、编码格式或发布组。

运行 `--dry-out` 预览仍可能访问 Bangumi 和调用媒体探测，只是不执行改名。
